# Source and rights notes

This catalog points learners to the original publishers or repositories. It does not mirror the linked PDFs.

## Verified source notes

- **National Curriculum Development Centre (NCDC):** the PSHPE resource book and 2025 Biology and Geography syllabi state that all rights are reserved and reproduction requires prior permission. They are listed as link-only until written permission is obtained.
- **NCDC teacher-support PDF:** no redistribution permission was confirmed, so it is also link-only.
- **Fresh Teacher exams repository:** GitHub reports no repository license, and the repository has no LICENSE file. PDF rights are therefore not stated; records link to files at the source and do not grant permission to mirror them.

## Adding a mirrored file

Only add a PDF to this repository after documenting a license or written permission that allows redistribution. Record the rights evidence, attribution, author or publisher, and any required notice. A public URL or a code repository license is not by itself proof that included learning materials may be rehosted.

## Catalog fields

- rights_status: what was verified for the individual item.
- redistribution: link_only unless permission to mirror is documented.
- source_url: the original file or page.
- download_url: the original download endpoint.
- provider_url: the source collection or repository.
- source_version: pinned Git commit for repository-hosted files, when available.

This is source tracking, not legal advice. Contact the rights holder for permission where required.
